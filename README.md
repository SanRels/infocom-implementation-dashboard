# Панель управления внедрением ИС

## О проекте
Проект предназначен для планирования и отслеживания внедрения информационной системы.

## Цель
Организовать единое пространство для управления задачами, этапами внедрения и статусами выполнения работ.

## Структура проекта
- `backend/` — серверная часть приложения.
- `frontend/` — пользовательский интерфейс.
- `docs/` — документация проекта.

## Команда
- Team Lead / QA / DevOps — координация работы, контроль качества и настройка окружения.
- Backend Developer — разработка серверной части.
- Frontend Developer — разработка пользовательского интерфейса.

## Технологии
- GitHub для хранения кода и совместной работы.
- Docker Compose для запуска компонентов приложения.

## Статус
Начальная настройка проекта.
